Computer Engineering student from India. I build web apps and AI tools with Python, JavaScript and React.

## Pinned projects

- **[Custom RAG](https://github.com/PixelCraftLab/custom-RAG)**: chat with your PDFs. FastAPI and React app that answers from uploaded documents. Hybrid retrieval combines vector search on PostgreSQL with pgvector and BM25 keyword search, merged with Reciprocal Rank Fusion, then a Groq LLM writes the answer.
- **[Developer Portfolio](https://github.com/PixelCraftLab/portfolio)**: my portfolio site built with React, Vite, Tailwind CSS and 3D and motion effects (Three.js, GSAP, Framer Motion). [Live](https://portfolio-gray-seven-gfpfkm8wp8.vercel.app)
- **[House Price Prediction](https://github.com/PixelCraftLab/house-price-prediction)**: linear regression model on property features, served through a Streamlit app.
- **[Shop Store](https://github.com/PixelCraftLab/shop-store)**: React storefront with landing, login, register, shop and dashboard pages. [Live](https://shop-store-tidw.vercel.app/)
- **[Tic Tac Toe](https://github.com/PixelCraftLab/Tic-Tac-Toe-XOX-)**: two-player game in HTML, CSS and JavaScript. [Play](https://tic-tac-toe-xox.vercel.app)
